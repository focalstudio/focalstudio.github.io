# CLAUDE.md

Instructions for this repo live in [`AGENTS.md`](AGENTS.md). Read it first.

## Workflow
1. Check `git status` and the current branch before editing.
2. Never work directly on `main`; use `feat/*`, `fix/*`, or `docs/*`.
3. Keep changes minimal and limited to the requested files.
4. Open a PR to `main` with a clear summary and file list.

## Safety
- Do not use destructive git commands without explicit approval.
- Do not revert user edits that were not part of the requested task.
